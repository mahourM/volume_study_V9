5. Entry Evaluation در Python

text

6. محاسبه final_stop_loss
محل:
داخل TradingDecisionEngine
قبل از ساخت command نهایی OPEN
برای BUY:
text



final_stop_loss = min(
  trading_timeframe_stop_loss,
  same-direction lower timeframe suggested_stop_loss values
)

برای SELL:
text



final_stop_loss = max(
  trading_timeframe_stop_loss,
  same-direction lower timeframe suggested_stop_loss values
)

قواعد:
فقط lower timeframeهای هم‌جهت وارد محاسبه شوند.
NEUTRAL نادیده گرفته شود.
تایم‌فریم مخالف که باعث reject می‌شود اصلاً وارد محاسبه stop-loss نشود.
این فقط برای entry اولیه است.
re-entry stop-loss logic تغییر نکند.
